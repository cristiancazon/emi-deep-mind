## 🌟 What is EMI?

EMI is not just a chatbot; it's a **Next-Gen Personal Assistant** built entirely using the "Vibe Coding" philosophy. Every line of code, every design decision, and every integration was crafted with the assistance of advanced AI, leveraging the full power of the Google ecosystem.

It’s designed to be **fast, intelligent, and deeply integrated** with your digital life.

## 🚀 Key Features

### 🎙️ Live Mode (Real-time Voice)
Conversations with EMI are fluid and natural. Using **Gemini Multimodal Live API**, you can talk to EMI just like a human. It understands interruptions, tone, and context instantly.

### 📞 Call Mode
Need a hands-free experience? Switch to Call Mode for a dedicated voice interface that mimics a phone call, perfect for when you're on the move.

### 🧠 Contextual Memory
EMI remembers what matters. It doesn't just store logs; it detects **topics**, summarizes them, and keeps a long-term memory of your preferences, ensuring every conversation feels like a continuation, not a restart.
*Note: The chat window starts fresh every time for speed, but EMI remembers the context!*

### 🛠️ Google Ecosystem Integration
EMI is a true power user of Google tools:
- **📅 Google Calendar**: "Schedule a meeting for tomorrow at 3 PM."
- **📧 Gmail**: "Draft an email to John about the project." (EMI shows you the draft before sending!)
- **✅ Google Tasks**: "Remind me to buy milk."
- **📍 Google Maps**: "Find the nearest pharmacy."
- **📰 Google News**: "What's happening in tech today?"

## 🏗️ Technology Stack (100% Google)

This project is a showcase of Google's cutting-edge developer tools:

- **Brain**: [Gemini 2.5 Flash](https://deepmind.google/technologies/gemini/) (Multimodal & Fast)
- **Frontend**: Next.js (React) hosting on **Google Cloud Run**
- **Backend/Db**: **Firebase** (Firestore, Auth, Hosting)
- **Voice/Audio**: Gemini Multimodal Live API via WebSockets
- **Deployment**: CI/CD via Cloud Build & Artifact Registry

## 🔮 The "Vibe Coding" Philosophy

"Vibe Coding" means building software at the speed of thought. EMI was created by iterating in natural language, letting AI handle the implementation details while the creator focused on the *soul* and *utility* of the application.

> *"We didn't just write code; we curated an experience."*

## 📦 Getting Started

1.  **Clone the repo**
2.  **Set Environment Variables** (See `.env.example`)
3.  **Run Locally**: `npm run dev`
4.  **Deploy**: Push to main (Auto-deploys to Cloud Run)

*(Remember to set `GEMINI_API_KEY` in your Cloud Run secrets!)*
